# Code of Conduct

## Our Pledge

This project exists to advance AI safety research. All contributors and users are expected to uphold ethical standards in both their contributions and their use of this software.

## Standards

**Acceptable:**
- Using the tool to test systems you own or have authorization to test
- Contributing attack modules grounded in published academic research
- Reporting bugs, suggesting features, and improving documentation
- Discussing AI safety, red-teaming methodology, and responsible disclosure

**Not Acceptable:**
- Using this tool to attack AI systems without authorization
- Contributing attack modules designed to extract CBRN, CSAM, or similarly harmful content
- Harassing maintainers or contributors
- Distributing results of unauthorized testing
- Using this project to circumvent safety measures for malicious purposes

## Enforcement

Contributions or issues that violate this code of conduct will be closed without engagement. Repeat violations will result in a permanent ban from the repository.
