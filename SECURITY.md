# Security Policy

## Reporting Vulnerabilities in This Tool

If you discover a security vulnerability **in this toolkit itself** (not in a third-party AI system you tested with it), please follow responsible disclosure:

### Do

- Email the maintainer privately **before** opening a public GitHub issue
- Include a clear description of the vulnerability and reproduction steps
- Allow reasonable time (up to 30 days) for a fix before public disclosure

### Do Not

- Open a public issue for unpatched vulnerabilities
- Exploit the vulnerability beyond what is necessary to demonstrate it

### Contact

Open a **private** GitHub security advisory via:  
`Security` tab → `Report a vulnerability`

---

## Scope

This policy covers:
- The toolkit codebase itself
- The TUI application
- Report generation logic

This policy does **not** cover vulnerabilities you discover in third-party AI systems while using this tool. For those, follow the affected vendor's own responsible disclosure program.

---

## Out of Scope

- Vulnerabilities in third-party dependencies (report directly to those projects)
- Issues that require physical access to the machine running the tool
- Social engineering attacks against the maintainer
